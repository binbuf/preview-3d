Preview3D third-party notices
=============================

This distribution contains components restored from the vcpkg baseline recorded
in SBOM.cdx.json and MANIFEST.json. The complete upstream notices/license texts
installed by those pinned ports are preserved in licenses\; the index below is
generated from the installed dependency closure at packaging time:

@LICENSE_LIST@

The installed distribution also contains Preview3DThumbnailProvider.dll, the
Explorer thumbnail provider. Its upstream parser/decoder/codec and constrained
OCCT dependencies (basisu, bzip2, draco, fastgltf, ktx, lib3mf, libwebp, libzip,
meshoptimizer, opencascade, simdjson, tinyusdz, ufbx, zlib) are statically linked
into that single image, so no upstream DLL is shipped separately. The provider's
own name and its statically linked closure are recorded in SBOM.cdx.json; its
resolved runtime imports are the app-local Microsoft Visual C++ Runtime files
only.

The app-local Microsoft Visual C++ Runtime files are Microsoft distributable
code supplied by the installed Visual Studio C++ toolset. Their redistribution
is governed by the Microsoft Visual Studio license terms for the build tools.

Windows graphics, imaging, shell, and Universal CRT system components are used
from Windows and are not copied into this archive.
