document records what was actually built and run; it is not a feature
announcement. Where a claim is narrower than the implementation, the narrower
claim is stated here.

## 0.7.0 fixes made during qualification

- **Viewer startup regression (T18).** The textured D3D12 root signature
  exceeded the 64-DWORD limit after the material-lobe block was added
  (33 + 36 constants + CBV/tables), so `CreateRootSignature` failed and every
  viewer start reported "The textured D3D12 root signature could not be
  created." Qualification fixed it by packing the lobe block into three
  `float4` rows plus the existing emissive `.a` slot, and by sending a
  transposed 3x4 local transform and a 3x3 normal matrix (explicit `float4`
  rows) for the textured pipeline. The signature is now exactly 64 DWORDs;
  shader semantics and goldens are unchanged.
- **Stale tests.** `FormatRegistrationTests` still rejected `dae`; 
  `ActiveInstanceTests` still rejected `iges`. Both now assert the shipped
  catalog. `PresentationTests`/`GroundShadowTests`/`MaterialLobesTests` were
  updated for the packed lobe layout.
- **Stale app-smoke expectations.** The recovery smoke expected the pre-3MF
  `UnsupportedFormat` for a non-ZIP `.3mf`, `UnsupportedEncoding` for ASCII
  STL/PLY and a required-extension veto; it now expects the shipped typed
  outcomes (`ArchiveLimit`, `EmptyGeometry`). The STEP smoke expected external
  STEP declarations to be rejected; it now verifies the T07 warning path and
  the geometry-free `EmptyGeometry` case. No assertion was removed.
