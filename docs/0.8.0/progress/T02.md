## What landed

- `catalog_detail::kStepExtensions` = `step`, `stp`, `stpnc`, `p21`, `210`.
  Same `FormatId::Step`, stable name `step`, ProgID
  `Binbuf.Preview3D.STEP.1`, thumbnail CLSID and host.
- NSIS install/uninstall lists, `FamilyRouting.h`, and the staged
  `Preview3DThumbnailRegistration.ps1` table now carry all five suffixes.

- `[format-aliases]` covers case-insensitive lookup, the direct-open list, the
  Open As text, the NSIS lists, the provider route, and the PowerShell table.

  lists and the full ProgID table in design/08 and design/07; STL/PLY rows now
  name their suffixes explicitly.

- Catalog aliases are stored lowercase without a dot; `EqualExtension` folds
  case, so `.STPNC`/`.P21`/`.210` work through the same lookup.
- Drift surfaces for a suffix: `FormatCatalog.h`, `Preview3D.nsi`
  (`RegisterExtension` + `UnregisterExtension`),
  `thumbnail-provider/FamilyRouting.h`,
  `packaging/installer/Preview3DThumbnailRegistration.ps1`,

  `tests/app-smoke/step_package.py`,
  `interactive-viewer/src/platform/OpenWithRanking.cpp`, and
  `packaging/installer/Reset-Preview3DTestAssociations.ps1`.
- The `[format-aliases]` test parses the PowerShell `Clsid`/`Extensions` blocks
  and compares them with `FamilyRoutes()`; it also unions catalog descriptors
  per family (glTF covers `.gltf`/`.glb`, USD covers four suffixes).
- The alias fixtures already existed from T01 and are byte-identical copies of
  `tests/fixtures/stp-spike/part_ap214.stp`; do not regenerate them by hand.
- Valid-file report: `artifacts/valid-file/<Configuration>.json`. The three
  alias rows show `stage=Completed`, `geometry=triangles`, `triangles=64`,
  no warnings.

## Gotchas

- Rebuilding `Tests.ImportIsolation` is required after a catalog-header change:
  the catalog is compiled into the harness, while the manifest is read at
  runtime. The executable's old catalog would fail the flipped alias rows.
- MSBuild output can show `LNK4099` warnings (missing `vc145.pdb`) and a
  compressed-summary line that looks like `1 FAIL`; check `$LASTEXITCODE` or
  the produced binary instead of the summary text.
- Do not invoke `makensis`; the installer drift test only reads the `.nsi`.
- The thumbnail route is CLSID-only; the alias suffixes are registration keys,
  not adapter dispatch inputs. The STEP adapter consumes the stream and still
  performs Part-21 admission.
