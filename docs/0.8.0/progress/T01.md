## Gotchas

- Building this solution with `/m` (parallel MSBuild) in this environment can
  hit `C1041` on the shared `tests/import-isolation/x64/<Config>/vc145.pdb`.
  Use `/m:1 /p:MultiProcessorCompilation=false`, and stop stale
  `MSBuild`/`cl`/`mspdbsrv` processes first.
- `RunImportSession` needs `PREVIEW3D_IMPORT_WORKER_EXE`,
  `PREVIEW3D_IMPORT_HOST_EXE` and `PREVIEW3D_STEP_HOST_EXE`; the vcxproj
  already defines them with `$(SolutionDir)`. When building the project
  directly, pass `/p:SolutionDir=<repo>\`.
- The report is `artifacts/valid-file/<Configuration>.json` and contains
  manifest ids/stable format names only. It is evidence; `[valid-file]` is the
  gate.
- Regenerating the real-world copies needs the local F3D checkout:
  `python tests/fixtures/valid-file/generate_fixtures.py --f3d-data D:\repos\github\f3d\testing\data`.
- `points.dae` currently opens as triangles; that is a measured fidelity gap,
  not a passing point-only case. `points.x3d` is the point-only primitive gap.
