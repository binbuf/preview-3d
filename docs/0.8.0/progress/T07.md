# T07 — Reader registry, scores and force-reader

## What landed

  product-owned reader table (ADR-0101). `ReaderDescriptor` has `name`,
  `displayName`, `family`, `importer`, `extensions`, `score`,
  `isCompatibility` and `optionNames`. Eleven readers in stable name order:
  `3mf`, `assimp`, `cad`, `fbx`, `gltf`, `obj`, `ply`, `step`, `stl`, `usd`,
  `usd-compat`.
- Pure lookups: `Readers`, `FindReaderByName`, `ReaderOwnsExtension`,

  `ReadersForFamily`, `DefaultReaderForFamily`, `DefaultFormatForFamily`,
  `ReaderChoicesForFamily`, `ImporterKindName`, `SelectDefaultReader`,
  `ResolveForcedReader`. Scores are product policy; default = highest score,
  ties by stable name; compatibility readers score below native ones.
- `interactive-viewer/src/app/OpenOptions.h` — `ParseReaderName`
  (`ReaderParseError`), `BuildReaderListText` (`name<TAB>extensions<TAB>
  importer<TAB>score`), `OpenAsFamilyEntries` (default + alternates per
  family), `BuildOpenAsReaderText`, `ReaderLabel`,
  `ReaderSelectionDiagnostic`.
- `Preview3D.cpp` — `--list-readers`; `--reader <name>` / `--reader=<name>`
  (ASCII case-insensitive, 64-char bound); `--reader` wins over `--format`;
  unknown names print a bounded stderr line and exit 2 before any open.
  `BeginOpen` gained a `forcedReader` argument and resolves it against
  `ClassifyForOpen`. Open As lists families/readers, marks `[default]`, checks
  the forced reader, sets it for an alternate and clears it for the default.
- `InfoPanel.{h,cpp}` — optional `readerLabel` parameter appends a `Reader` row
  to Scene Data after the existing rows (so `rows[2]` remains Format).
- Broker: `ImportSessionRequest::forceCompatibilityHost` (closed bool) routes a
  forced `usd-compat` USD open straight to the OpenUSD compatibility host.
  Non-USD + the flag is `ValidateOptions`/`ImportProtocolViolation`; USD with
  no host path is `LaunchWorker`/`CompatibilityHostFailure`. The reader name
  never crosses the process boundary.
- Tests: `tests/unit/ReaderSelectionTests.cpp` (tag `[reader-selection]`, 8
  cases / 660 assertions) and one `[import-session]` case in
  `tests/import-isolation/ImportSessionTests.cpp` for the closed broker route.
- Docs: `docs/FORMAT-SUPPORT.md`, `README.md`,
  `docs/tasks/0.8.0/README.md`, `docs/design/03-file-formats-and-ingestion.md`,

## Gotchas

- **Rebuild the ImportIsolation object directory after changing
  `D3D12ImportBridge.h`.** The vcxproj does not track that header as a
  dependency for every object, so stale objects link against the old
  `RunImport` signature. Delete `tests/import-isolation/x64/<config>` and
  rebuild (same gotcha T06 recorded).
- `ReaderCatalog.h` stores the table in stable name order. `--list-readers`
  prints it verbatim; insert a new reader at its sorted position rather than
  appending it, or the listing test fails.
- The `usd-compat` reader's descriptors declare `ImporterKind::UsdFastPath`
  (the catalog has one USD descriptor set). The reader itself is
  `UsdCompatibilityHost`; the resolver sets `forceCompatibilityHost` from the
  reader, not from the descriptor. Do not add a second USD descriptor.
- `cad` and `assimp` are multi-family readers. They must not invent a fallback
  for an unowned suffix; that is a typed `ReaderCannotOpenFormat`. Single-
  family readers (`gltf`, `step`, `usd`, ...) do fall back to their own family
  and let the worker/host reject the bytes.
- `BuildOpenAsReaderText` uses `FindById(family)->stableName` for the family
  column. Every family currently has a descriptor with the same `FormatId`, so
  the text is stable; a future family without one prints `unknown`.
- `--reader` is applied by `BeginOpen`. The initial path, retry, initial-open
  command and missing-asset re-import all forward `app.forcedReader`; a plain
  Open dialog/drag-drop clears it, matching the existing `--format` behavior.
- The info-panel Reader row is appended after Units so existing tests that
  index `sections[5].rows[2]` for Format keep working.
