# T03 — Catalog-driven registration, filters and Open As

## Reusable facts

- Core policy: `shared/model-core/include/model_core/FormatSelection.h`.
  `DecideOpenFormat` returns `OpenExtension` for a known suffix, `AskUser` for
  content-only or cross-family mismatch, `Reject` for nothing. `FormatChoiceSummary`
  is the path-free diagnostic string. `ProgIdForFormat`, `IsImportableFormat`,
  `DirectOpenExtensions` and `ImportableFormatDescriptors` are catalog-derived.
- CLI helpers: `interactive-viewer/src/app/OpenOptions.h`.
  `--format` accepts a **stable name** (case-insensitive), not an extension
  alias: `stp` is invalid, `step` is the stable name. Both `--format <name>` and
  `--format=<name>` work; reserved identities without a shipped importer
  (e.g. `iges`) are rejected. `--skip-content-check` skips `SniffFile`.
  `--list-formats` emits `stable-name<TAB>extensions<TAB>display-name` per
  directly registered format and exits before window creation. Redirect stdout
  for reliable capture; the code also reopens `CONOUT$`.
- Bridge: `ClassifyForOpen(path, skipContentCheck)` and
  `SourceFormatForFormatDescriptor`. Internal helper is
  `SourceFormatForCatalogDescriptor`.
- Open As UI: `ID_VIEW_OPEN_AS` in `Resource.h`, accessibility
  `Control::ErrorOpenAs` appended after existing IDs. The failure-card button
  lists detected/suffix candidates first, then every importable format; the
  chosen descriptor forces the re-import. Forced success appends
  `Opened as X. Detected Y.` to the model warning; failure appends it to details.
- Installer approach: explicit NSIS calls retained. `[format-installer]` parses
  `packaging/installer/Preview3D.nsi` and checks the exact install/uninstall
  macros, ProgIDs and uninstall keys for every catalog extension in both
  directions. No catalog/installer drift found.
- `ActiveInstance` uses `model_core::FindByExtension`+
  `IsImportableFormat`; `ShellIntegration` enumerates `DirectOpenExtensions`;
  the open-dialog filter is built per catalog family.

- No catalog/installer drift was present.

## Gotchas

- Build `Tests.Unit` through `Preview3D.slnx`; a direct `.vcxproj` build makes
  `$(SolutionDir)` the project directory, so `PREVIEW3D_REPO_ROOT` points at
  `tests\unit` and the installer test cannot find `Preview3D.nsi`.
- `FormatDescriptor::extensions` is a span of `std::wstring_view`. Converting
  through `std::string(begin,end)` trips C4244 (warnings are errors); narrow
  explicitly.
- Windows may briefly lock a freshly linked `Tests.Unit.exe`; retry LNK1104
  after a few seconds.
- `--skip-content-check` is process-wide; Open As/`--format` forces one open.
- Direct console output from the GUI-subsystem executable depends on console
  attachment; redirection works and was the tested form.

## Follow-ups

- Single-instance forwarding still carries only a path, so a secondary
  `--format` is not forwarded to a running primary. Extend
  `active_instance::Command` with a stable format name if needed.
- Generated NSIS include remains optional; the checked explicit calls plus
  `[format-installer]` are the accepted approach.
- T04+ should call `DecideOpenFormat` instead of re-deriving precedence.
- T08–T10 must append descriptors and NSIS entries together; the drift test
  fails until both land.
