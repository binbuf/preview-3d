# T27 — scene-color transmission and tinted/rough glass

## Status: done

Thin-surface scene-color transmission is the product path. The full gate passes
at `TestResults/render-quality/T27` (109 focused checks, 0 failures, 12 profile
captures, external Car/Camera/Suit available, review recorded). The generated
lane also runs standalone and passes.

## Reusable facts

- **Source sample**: `D3D12ViewerPath::GenerateTransmissionMips` copies the
  finished opaque `R16G16B16A16_FLOAT` scene into
  `transmission.sceneCopy` (`MipLevels = kTransmissionMipCount = 8`) after the
  opaque pass and before any transmissive draw. Mips 1..7 are full-screen
  downsample draws (`kTransmissionMipPixelShaderSource`). No pass samples a
  render target it is writing.
- **Shader**: `gTransmissionSource` is t15, root parameter 18. Frame constants
  carry `gTransmissionFrame = (1/sceneWidth, 1/sceneHeight, mipCount-1,
  usable)`. `mip = lastMip * perceptualRoughness` (linear in roughness).
  Transmitted radiance is
  `background * baseColor * transmissionFactor * (1 - interfaceFresnel)`.
  `interfaceFresnel` is IOR-only (`IorToF0`), zero for IOR <= 1.
- **Fallback when the opaque copy has alpha 0**: studio environment sampled in
  the transmitted direction (`-worldView`) at the selected roughness mip.
- **Coverage**: BLEND keeps authored alpha; OPAQUE/MASK cover 1. Interface
  Fresnel/transmission never enter coverage. Debug channel 9 shows effective
  coverage, 10 effective transmission, 22 `(coverage, interfaceFresnel,
  authoredTransmission)`, 28 authored transmission, 31 transmitted radiance,
  32 raw scene sample.
- **OPAQUE routing**: `isForwardTransmission` (complete-vertex textured OPAQUE
  with `kMaterialFlagTransmissive`) joins the transparent bucket. BLEND
  transmissive was already there. MASK never gets the flag. The fallback sorted
  path must restore `OMSetRenderTargets(targets, dsv)` after the mip pass
  (fixed).
- **Double-sided**: transmissive double-sided surfaces shade the authored face
  the camera sees. A single plane is one interface and is visible from both
  sides; a closed shell contributes both surfaces as two bounded OIT thin
  interfaces. Do **not** discard back faces for transmissive: it makes a
  single authored plane vanish from behind (this broke the T25 transmission-map
  probe).
- **Debug snapshot**: while `debugChannel != 0`, the snapshot is not
  regenerated. Channels 31/32 therefore read the last **product** frame's
  opaque scene, not the debug-channel image. Capture a normal (channel 0) frame
  at the same camera before switching channels.
- **Fields**: 259/260 = transmission bytes low/high, 261 = mip count (0 when
  unavailable), 262 = reason (0 none, 1 allocation failed, 2 unsupported
  extent, 3 forced, 4 device loss), 263 = OPAQUE transmissive draw count.
  Debug env switch: `PREVIEW3D_TEST_TRANSMISSION_ALLOCATION_FAILURE=1`
  (Debug test-control only) forces reason 3.
- **Budget**: at 1280x900 the snapshot+mips is 12,582,912 bytes
  (`TransmissionTargetBytesForExtent`); it is included in
  `AccountedAllocationBytes` and recreated by `CreateSceneColorTarget` on
  resize/recovery. `RefreshTransmissionDescriptors` rewrites the model and
  pending-model heap slot after target recreation.
- **Tint invariant**: `transmitted / background / baseColor` must be the same
  interface weight in every channel. Measured ~0.959 for IOR 1.5 at NoV ~1
  (F0 0.04). The lane uses this instead of comparing against a self-created
  golden.
- **Roughness invariant**: channel 32 p90 inside the rough panel must fall below
  0.8x the smooth panel's p90. Checker cells are 0.6 units; `mip=last*roughness`
  is enough with 8 levels (rough 0.75 -> 5.25).
- **Fixture**: `transmission-glass.glb` (`fixtures.py::transmission_glass`) has
  a two-primitive unlit checker wall at z=-0.9, an opaque interior at z=-0.78
  (red/blue) with a nearer inset, and 15 panels: neutral, orange, dark blue,
  rough, BLEND coverage 0.4 with transmission 0.25/1.0, IOR=1, MASK cutout,
  two-layer overlap, interior glass and a double-sided thin plane. All panels
  have TANGENT/COLOR_0 so the complete-vertex shader is selected.
- **Winding**: `_quad_at` in `fixtures.py` is CW (T26 relies on doubleSided).
  The T27 fixture flips indices to `[0,1,2,2,1,3]` **and** uses +Z normals so
  single-sided panels are front-facing with NoV=1. Mismatched winding/normal
  makes the interface Fresnel look grazing (weight 0) even though the panel is
  visible.
- **DPI / sampling gotcha**: `verify.py` calls `set_dpi_awareness()`; the
  PrintWindow image is then ~1258x745 for a 1280x900 request, while a direct
  `python -c` run without it can capture at the physical 1.5x size. In both
  cases the debug-sample request accepts image coordinates + `frame['rect']`
  offsets. Locator boxes include anti-aliased edges; use `_role_points` (matches
  the isolated base-color image, shrinks the box by 1/8) and sample interiors.
  Do not scale image coordinates by DPI. `sample_region` clamps to a 64x64 tile;
  use it point-wise or `region_sample` for larger areas.
- **T25 regression**: the transmission-map probe sits at the bottom edge. T27's
  pass change exposed that the probe was clipped; `textured_lobes.py` now uses
  camera distance 1.6 instead of 1.35 so the full 3x3 probe grid fits. Re-ran
  `textured_lobes.run(..., fast=True)` -> pass.
- **T26 regression**: `layered_transparency.run(..., fast=True)` still passes;
  its fixture has no transmission flags.
