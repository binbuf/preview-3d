# T17 - Line/strip/fan/point topology

## Reusable facts

- **Wire version is 11** (`model_core::kCurrentProtocolVersion == 11`).
  `ChunkTopology::LineList = 11` is append-only; v10 numeric identities are
  unchanged. Any test that pinned protocol 10 must now expect 11.
- **LineList contract.** Payload is `[vertex bytes][uint32 indices]`, exactly
  like TriangleList. `indexCount` is even and each pair
  `{indices[2i], indices[2i+1]}` is one independent segment. No strips/loops on
  the wire. `PointList` remains no-index. Helper functions in `WireFormat.h`:
  `IsGeometryTopology`, `GeometryPrimitiveCount`, `GeometrySourceElementCount`.
- **Validator rules** (`shared/import-broker/src/SharedSectionValidator.cpp`):
  odd LineList index count -> `MalformedData`; out-of-range index ->
  `MalformedData`; byte size must equal `vertexCount*stride + indexCount*4`;
  LineList uses the same vertex-count/byte caps as TriangleList.
- **ImportSession accounting** uses `IsGeometryTopology`; line source
  provenance length equals `indexCount`; progressive primitive counts use
  `GeometryPrimitiveCount` (line = indexCount/2).
- **Coarse/proxy sampling** (`import-worker/src/CoarseSampler.h`) treats a line
  primitive as two corners; deindexed parallel sampling stays triangle-only.
- **glTF** (`import-worker/src/GltfAdapter.cpp`,
  `ConvertNonTrianglePrimitive`): strips/fans -> indexed TriangleList (stitch
  degenerates dropped); LINES -> LineList; LINE_STRIP/LOOP -> pair list;
  POINTS -> PointList. Odd LINES index count is `MalformedData`.
- **OBJ** (`import-worker/src/ObjAdapter.cpp`, `EmitObjLinePointGeometry`):
  ufbx does not surface `l`/`p`, so when no triangles exist the bounded text
  source is scanned directly. `l` becomes an open-polyline pair list, `p`
  becomes PointList; invalid/out-of-range tokens and too-short elements are
  `MalformedData`, not `EmptyGeometry`.
- **FBX** (`import-worker/src/FbxAdapter.cpp`, `EmitLineCurves`): ufbx
  `line_curves` emit LineList pairs transformed by `geometry_to_world`;
  malformed curve indices are `MalformedData`.
- **Viewer**: `D3D12ViewerPath` owns `linePipelineState` (position-only VS/PS,
  `D3D12_PRIMITIVE_TOPOLOGY_TYPE_LINE`, negative depth bias, depth writes off,
  `LESS_EQUAL`, stable grey-blue). `GpuMesh::lines` drives
  `D3D_PRIMITIVE_TOPOLOGY_LINELIST`; lines still write the pick target and
  participate in bounds/visibility/LOD.
- **Cache identity**: `interactive-viewer/src/cache/DerivedCache.cpp`
  `kCurrentCacheSchemaVersion = 2`; a v1 entry cannot be reused because
  normalized bytes/topology changed.
- **Fixtures** (`tests/fixtures/topology/`, own content, data-URI glTF):
  triangle_strip, triangle_fan, line_strip, line_loop, lines, line_only.obj,
  point_only.obj. `tests/import-isolation/TopologyTests.cpp` opens them through
  the real sandboxed session.
- **Hostile worker**: `--lie-line-topology` publishes a structurally honest
  LineList with three indices; `HostileWorkerTests.cpp` checks `MalformedData`.

## Gotchas

- `TopologyTests.cpp` needs `#include "import_broker/SharedSection.h"` for
  `kImportSectionBytes`; including only `ImportSession.h` does not provide it.
- OBJ `l`/`p` parsing must distinguish "end of line" from a malformed token.
  A silent false return turns an out-of-range index into `EmptyGeometry`.
- `ConvertNonTrianglePrimitive` splits line payloads on even counts and triangle
  payloads on multiples of three; never let the last partial primitive through.
- glTF strip winding alternates per triangle; test triangle (2,1,3), not
  (1,2,3), for index order 0,1,2,3.
- `preview`/scan summaries of LineList store `ScanSummaryPayload` exactly like
  triangles; the validator's scan path skips index/odd checks by design.

## Follow-ups

- USD `BasisCurves`/`NurbsCurves` still classify as
  `UnsupportedRequiredFeature`. A follow-up can emit bounded polylines as
  LineList without another wire change.
- STEP wires are still tessellated as triangles; emitting `read_wire` edges as
  LineList would need a STEP-host option and a viewer toggle.
- Line material/color: the current line PSO is constant grey-blue and binds no
  Material chunk. Material lobes are T18 scope.
- Line picking uses the existing rasterized pick target; narrow-line picking at
  extreme zoom is not separately validated.
- No line-width/roundness policy was needed; D3D12 line rasterization uses the
  device default 1-pixel width.
