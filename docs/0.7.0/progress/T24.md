## Reusable facts

- **Gate:** `python tests/render-quality/verify.py --task T24 --configuration Debug --output TestResults/render-quality/T24`.
  Builds `Preview3D`, `Tests.Unit` and (full lane) `Tests.ImportIsolation`,
  runs `[brdf]`, `[material-lobes]`, `[studio-ibl]`, `[gltf-extensions]`, the
  capture lane for brdf-probe + Car/Camera, then `brdf.py`'s GPU lane and the
  image-review gate. Exit 1 on any failure. `--fast` skips the import suite,
  external corpus, F3D and review; it is iteration only.
- **CPU API** (`interactive-viewer/src/render/StudioEnvironment.h`):
  `CubemapTexelSolidAngle`, `ProjectCubeIrradiance`,
  `PrefilterSpecular`, `ReferencePrefilteredRadiance`,
  `BakeBrdfLut`, `SampleBrdfLut`, `ReferenceBrdfIntegration`,
  `EnvironmentBrdfFresnel`. All are pure CPU; `[brdf]` runs them without a GPU.
- **LUT convention:** R32G32_FLOAT 64²; x = NoV, y = perceptual roughness;
  `A`/`B` are `∫(1−Fc)G_vis D(n·h)dω` and `∫Fc G_vis D(n·h)dω`.
  `EnvironmentBrdfFresnel(F0=1, weight=1)` is exactly 1.
- **Shader:** `gBrdfLut` is `t6`, root descriptor table 9; the cubemap stays
  `t4` table 5 and occlusion `t5` table 6. The LUT SRV lives at
  `ModelResources::brdfLutDescriptorIndex` (environment index + 1) in each
  material heap. Add a descriptor whenever a heap is created/rebuilt.
- **Diagnostic channels:** 21 = `F0·A+B` environment scale, 22 =
  `(alpha, glassReflectance, transmission)`, 23 = flat 0.3 linear
  display-calibration patch. Field 124 accepts 0..23; mask 0..23; UV1 (5)
  remains unsupported. Debug fields 231/232 = last resolve exposure/tone map.
- **T24 lane:** `tests/render-quality/brdf.py`; profile
  `tests/render-quality/profiles/T24.json`; fixture `brdf-probe` (16 probes,
  4×4) in `fixtures.py`. The numeric session disables grid, shadow and ground
  highlight (fields 104/102/196 = 0) because their neutral display values
  would compete with the white probes in the base-colour locator.
- **Evidence:** `TestResults/render-quality/T24/report.json`,
  `diagnostics/brdf.json`, `diagnostics/channels/channel-*.png`,
  `images/generated-brdf-probe-*.png`, `external/car-*.png`,

- **Run time:** full gate roughly 3-5 min warm; the brdf lane is ~2 min

## Gotchas

- Do not run two `Preview3D.exe` instances. A leftover viewer from an ad-hoc
  script steals the single-instance window and the capture lane fails with
  UI error 1400 (`ERROR_INVALID_WINDOW_HANDLE`). Kill stale
  `Preview3D` processes before the gate.
- The HDR readback uses **absolute scene-target pixels** (`rect.top + centroid`);
  the capture is cropped by the toolbar. A flat debug patch (channel 23) avoids
  the one-pixel spatial mismatch that makes a gradient-pixel tone-map comparison
  noisy. Use channel 23 for the exact CPU/GPU tone-map check.
- `SetDebugChannel` must be sent with field 124 and lParam 0..23; use lParam -1
  only to query. `channel_supported` reads field 125.
- The `T24` profile's capture lane keeps the product presentation (grid/ground
  on). The numeric lane turns them off; do not compare their images directly.
- `T24` full lane builds the import suite with
  `/p:SolutionDir=<repo>\`; a direct project build loses the asset/worker paths.
- Release builds the same shader; the test-control handler is compiled out, so
  fields 124/231/232 return 0 there.
