# T02 — Format catalog and content-aware router

## Reusable facts

- Catalog: `shared/model-core/include/model_core/FormatCatalog.h` (header-only
  constexpr table + pure lookups). `FormatId` 1..13 deliberately equal
  `SourceFormatId` 1..13; `FormatId::Usd = 14` is the generic `.usd` extension
  identity with no wire id.
- Reserved append-only `FormatId`s with **no descriptor yet**: `Iges=15`,
  `Brep=16`, `Xbf=17`, `Fcstd=18`, `Dae=19`, `ThreeDs=20`, `Off=21`, `Amf=22`,
  `Vrml=23`, `X3d=24`. T07-T10 append descriptors; do not renumber.
- Wire-only descriptors `AsciiStl=5` / `AsciiPly=6` intentionally own no
  extension, so every extension has exactly one owner. Binary STL/PLY and the
  ASCII variants share `family` (`Stl`/`Ply`).
- Catalog lookup helpers: `Formats()`, `FindByExtension` (dot optional,
  case-insensitive), `FindByStableName`, `FindById`,
  `FindBySourceFormatId`.
- Sniffer: `shared/model-core/include/model_core/FormatSniffer.h` +
  `src/FormatSniffer.cpp`. `SniffHead(span,total)` is pure; `SniffFile(path)`
  adds the ZIP probe. Bounds: head 64 KiB, central directory 1 MiB / 8192
  entries, EOCD search 64 KiB. No decompression.
- Signatures implemented: GLB (`glTF` v2 + declared length <= file), glTF JSON
  (`{` + `"asset"` + `"version"`), PLY header, binary STL (84-byte prefix,
  50-byte facet count, <=1 KiB trailing tolerance), ASCII STL (`solid` +
  `facet` + `endsolid`), OBJ (`v` plus `f`/`p`/`l` statements), FBX binary
  (`Kaydara FBX Binary`) and ASCII (`; FBX`), USDA (`#usda`), USDC
  (`PXR-USDC`), STEP (`ISO-10303-21`), 3MF (`[Content_Types].xml` in the
  central directory), USDZ (`.usd`/`.usda`/`.usdc` entry in the central
  directory).
- `ClassifyFormat(extension, SniffResult)` returns extension/content/selected
  descriptors plus reason `Extension|Content|Both|Mismatch`. Same `family`
  counts as `Both`; cross-family prefers content and reports `Mismatch`.
- App bridge: `ClassifyByContent`, `ClassifyForOpen`,
  `ExtensionSourceFormat`, `ClassificationDiagnostic` in
  `interactive-viewer/src/app/D3D12ImportBridge.h`. The open path still uses
  `classification.extension` only and logs path-free content/mismatch
  diagnostics via `OutputDebugStringW`.
- `SourceFormatLabel` and `ToBrokerFormat` now read the catalog. The catalog
  display key/name are `const char*`/`const wchar_t*` literals on purpose:
  `Loc()`'s fallback cache is keyed by pointer identity, so a temporary key
  `c_str()` can alias and return another format's cached fallback.
- Build/test:
  - `msbuild Preview3D.slnx /t:Tests_Unit /p:Configuration=Release /p:Platform=x64`
  - `x64\Release\Tests.Unit.exe "[format-catalog]"` — 350 assertions, 8 cases.
  - Same for Debug — 350 assertions, 8 cases.
  - `x64\Release\Tests.ImportIsolation.exe "[recovery]"` — 2312 assertions,
    37 cases (34 pass, 3 fault-harness skips).
  - `x64\Release\Tests.ImportIsolation.exe "[format-catalog]"` — 8 assertions
    (the bridge-level renamed-`.bin` case).
  - `x64\Release\Tests.ImportIsolation.exe "[compat]"` — 312 assertions.

## Gotchas

- `Tests.Unit` Release now sets `WholeProgramOptimization=false`. MSVC 14.51's
  c2 ICEs (C1001 in `GltfDataUriPreflightTests.cpp`) during LTCG for this test
  link; reproducing with all T02 sources removed showed it is pre-existing and
  unrelated. The shipped binaries keep LTCG.
- `Loc` takes `const char*` keys and caches fallbacks by pointer. Never pass a
  temporary string's `c_str()`; catalog keys are static literals.
- `SniffHead` cannot identify 3MF/USDZ (central directory is outside the head);
  use `SniffFile`. A ZIP head alone reports Unknown by design.
- A malformed GLB (`glTF` magic but bad version/truncated/declared length >
  file) returns Unknown rather than falling through to OBJ/text heuristics.
