## What landed

- **Default edge AA.** The resolve pass now runs a bounded seven-tap,
  depth/coverage-aware spatial filter. The four axial neighbours use a
  display-space luma/coverage probe; the centre blends with two full composite
  taps along the strongest gradient. A relative `1 - depth` discontinuity
  (geometry/occlusion) or coverage discontinuity gets weight 0.55; flat-depth
  texture detail gets 0.12 and low-contrast texture interiors are untouched.
  `viewer_aa` in `interactive-viewer/src/render/AntiAliasing.{h,cpp}` owns the
  thresholds and the CPU mirror used by tests.
- **MSAA/SSAA evaluation.** MSAA is rejected because the opaque pass writes the
  `R32_UINT` pick id in the same MRT set; resolving an integer target would
  average ids. Bounded 2× window supersampling is retained only as the
  deterministic validation reference in the lane.
- **Separation from picking and UI.** AA samples the existing scene, OIT,
  AO and depth resources in the resolve. It never samples the pick target, and
  the D3D11On12/Direct2D overlay is recorded afterwards. The depth SRV shares
  the resolve descriptor heap (t6) and adds no render target.
- **Sampling.** The material root signature's linear sampler is
  `D3D12_FILTER_ANISOTROPIC` with `MaxAnisotropy=4`; the nearest sampler stays
  point. Authored per-slot address/UV/nearest metadata is unchanged.
- **Semantic mips.** `GenerateRasterMips` now reduces Color/Emissive in linear
  light; the base-color map (`ColorCoverage`) is coverage-weighted alpha (no
  cutout color fringe) while other sRGB lobe colors keep a plain average.
  Normals renormalize, `MetallicRoughness` green uses GGX-alpha RMS, and Data
  maps stay a plain linear average. glTF/OBJ/FBX/USD and the OpenUSD
  compatibility host route base color and MR maps to the new semantics.
- **Diagnostics.** Debug fields 300-305: AA enable/disable, effective mode
  (0 off, 1 depth-aware, 2 unavailable), fallback reason, additional target
  bytes (always 0), tap count (7) and resolve CPU record microseconds. The
  Debug guard is extended to `wParam <= 305`.
- **Fixture/lane.** `edge-probe` in `fixtures.py` contains sub-pixel wires, a
  high-frequency grille, an engraved digit strip, a chrome sphere, a
  normal-map detail panel and a clear lens; the lane also uses `ao-probe`
  (MASK cutout), `layered-glass` (OIT) and `stl-box`. New
  `tests/render-quality/anti_aliasing.py`, `profiles/T33.json`,
  `review/T33-review.json`; `verify.py` routes T33 and includes it in the
  unit/import build tuple. `viewer.py` gained `resize_client` and corrected
  `pick_image` to use physical crop coordinates.

## Reusable facts / gotchas

- **Canonical camera pitch.** `SetTestView` pitch 0 is top-down; a front-ish
  view is around 70-73 with yaw 0. The edge fixture's role boxes assume
  `yaw 8, pitch 72.5, distanceScale 1.23`. Using pitch ~10 puts the vertical
  panels edge-on and makes AA look ineffective.
- **Yaw convention.** For this fixture yaw 0 is the front; yaw 180 looks at the
  backing panel. Keep the mode comparison at one camera so role regions align.
- **`pick_image` coordinates are physical crop pixels.** Do not multiply by
  `dpiScale`; `rect['top']` is already physical. `pick_at` works in client
  coordinates and is the quickest sanity check.
- **SSAA comparison.** Use `resize_client` with target client height
  `2 * viewportCropHeight + chrome`; the crop helper removes fixed physical
  chrome, so this makes the 2× crop exactly twice the 1× crop. Compare per
  region, not whole-frame MAE.
- **Fixture texture slot artifact.** The first edge-probe version carried four
  images (text/normal/MR/cutout); the cutout quad rendered with the wrong map
  (blue) while T29/T32's single-image cutout fixture was correct. The edge probe
  now keeps one map per visible semantic and the MASK coverage test uses
  `ao-probe`. Do not treat the removed quad as an AA result.
- **DPI field 67** simulates UI DPI (96/144/192) without relaunching; the
  capture helper still crops with the real window DPI, so those images are a
  lifecycle/layout check rather than first-open framing evidence.
