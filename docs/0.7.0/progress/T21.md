# T21 - material and light-contribution diagnostics

## Reusable facts

- **Wrapper:** `python tests/render-quality/verify.py --task T21 --configuration Debug --output TestResults/render-quality/T21`.
  It builds Debug and Release, runs the T20 contract self-tests, captures the
  T21 profile, runs `tests/render-quality/diagnostics.py`, builds the cause
  report and enforces the image-review record. Exit 1 on any failure.
- **New profile:** `tests/render-quality/profiles/T21.json`. Generated fixture
  `material-probe` (studio/front) plus external Car (front + window), Camera
  (front + lens) and Suit (front). `generated.regression` is false; T21 does not
  promote accepted baselines. `verify.py` only requires a comparison lane when
  a profile selects regression cases.
- **Diagnostic fields** (WM_APP+104, Debug + `--app-smoke` only):
  - 124 set/query diagnostic channel (`lParam == -1` reads), 125 support mask;
  - 126/127 sample rect min/max (packed 16-bit x/y client pixels);
  - 128 request HDR readback, 129 status (0 none, 1 pending, 2 ready, 3 failed),
    130-133 mean linear RGBA float32 bits;
  - 134 material count, 135 selected index, 136-194 material record.
  Do **not** query 124 with lParam 0: that sets channel 0. Use -1.
  Guard is now `wParam <= 200`; 195-200 are free.
- **Channels:** 0 normal; 1 base colour; 2/3 geometric/shading normal; 4 UV0;
  5 UV1 unsupported (magenta); 6 metallic; 7 roughness; 8 AO; 9 coverage alpha;
  10 transmission; 11 IOR/F0 (`ior/4`, F0); 12 clearcoat; 13 sheen; 14 direct
  diffuse; 15 direct specular; 16 env diffuse; 17 env specular (+sheen);
  18 coat; 19 emission; 20 pre-tone-map HDR.
- **Important shader routing:** diagnostic channels exist only in the *textured*
  shader (`PositionNormalUv0TangentColor_F32`). Fixtures that omit TANGENT/COLOR
  use the compact position+normal+UV shader, which ignores the channel. Any new
  material fixture must include TANGENT and COLOR_0 to exercise diagnostics.
- **Probe matching:** `diagnostics._centroids` matches the 8-bit display colour
  produced by `NeutralToneMap` + sRGB against the authored linear base colour.
  It does not rely on sphere layout or framing.
- **Release rejection:** launch Release normally (no `--app-smoke`; the flag is
  itself test control and exits 2). Send WM_APP+104 fields and require zero.
  T21 reuses the existing `x64/Release/Preview3D.exe`.
- **Run time:** ~4-6 min warm on this workstation (10 captures, 20 channel
  images, 71 numeric checks, 3 region surveys, Release launch). Diagnostics-only
  run is ~110 s.
- **Evidence:** `TestResults/render-quality/T21/report.json`,
  `diagnostics/diagnostics.json`, `diagnostics/channels/channel-*.png`,
  `cause-report.md`, `images/*.png`, `captures.json`,
  `tests/render-quality/review/T21-review.json`.

## Verified behavior

- 83/83 numeric/source checks pass: base colour, metallic, roughness, clearcoat,
  transmission, IOR/F0, UV1 unsupported marker, coverage alpha and the
  pre-tone-map HDR equals the sum of isolated lobes.
- Material records match the six source-authored probe materials and report
  bucket/depth-write/cull (opaque 0, masked 1, blended 2, transmissive 3).
- Region dominance (linear means): Car windshield environment-specular 0.698,
  Car paint environment-specular 0.188, Camera lens environment-specular 0.081,
  Camera black body environment-specular 0.023, Suit torso environment-diffuse
  0.093.
- T20 still passes with regenerated observed images in
  `TestResults/render-quality/T20-regression` (15/15 regression comparisons), so
  the split-light refactor did not change the default render.

## Flakes / gotchas

- A readback request needs the render loop to keep polling until the copy fence
  retires; `RenderThread` re-arms `invalidated_` while the sample is pending.
- The readback copies the HDR target before the resolve; sample rectangles are
  clamped to 64x64 and region surveys average up to 3x3 tiles.
- Do not run two viewers at once (single-instance activation steals the window).
- The diagnostic channel cannot be verified through the compact shader; this is
  why `material-probe.glb` now carries tangent/color attributes.
