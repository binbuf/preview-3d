# T23 — texture-budget accounting and complete-load readiness

## Status: done

The microscope's late failure is reproduced and measured, the false terminal
error is fixed at its source, duplicate image decoding is removed, and capture
readiness now requires a terminal resident load. The full T23 verification
command passes (see Hand-off in the task file for the exact run).

## Measured first failure (retained evidence)

Instrumented Debug probes opened `vintage_microscope_4k.gltf` and polled the
Debug test-control fields. The first failure was:

- `state = Failed`, `ImportErrorCode::ResourceLimit` (2),
  `ImportStage::GenerationDeadline` (17) at **~301 s**.
- At the failure: textures `extent 2048`, `count 4`, `mips 12`;
  `gpuBytes 134,742,016`; `targetBytes 1,023,410,176`; 20,631 triangles.
- So the limiter was the broker's absolute 300 s generation wall clock, not a
  decoded-byte/pixel, mip-chain, catalog, worker-commit or GPU-residency cap.
- The replay was idle: the viewer had stopped asking for visible regions and
  `nextDetail()` returned 0 until the deadline.

First-failure captures live under `TestResults/render-quality/T23-dev/` and the
review images under `TestResults/render-quality/T23-review-dev/` (ignored local
evidence). The plan-time screenshot is
`TestResults/render-quality-review/preview-microscope-resource-limit.png`.

## Fix

- **Bounded detail replay lifecycle.** New `ControlOpcode::EndDetail = 24`
  (host → worker, empty payload). `ChunkBatchSink::AwaitDetail` treats it as a
  clean end (`DetailEnded()`); the worker leaves the loop and the pool keeps the
  process. The broker ends an idle replay after `initialDetailGraceMs` (60 s)
  before the first request and `detailIdleGraceMs` (1.5 s) between requests, or
  at `maxDetailRequestsPerGeneration` (4096). An outstanding reply still hits
  the absolute generation deadline. The generation returns `Completed`, not
  `GenerationDeadline`.
- **Duplicate image source.** glTF image entries with the same URI/bufferView/
  content hash, semantic and color space reuse one pending image
  (`ImageSourceIdentity` + `imageSourceToPendingIndex`). sRGB color and linear
  data chunks stay distinct. The microscope now reports 3 resident model
  textures (was 4) and 112,263,168 GPU bytes (was 134,742,016).
- **No decode during detail replay.** A requested geometry range skips image
  decode; the scan batch already delivered the immutable image/material
  catalog.
- **Typed texture diagnostics.** `TextureBudgetKind` /
  `TextureBudgetDiagnostic` record the first refused resource with requested/
  allowed quantities, decoded totals and scratch reserve/limit. `_DEBUG` emits
  one value-only line; Release is silent.
- **Truthful readiness.** `wait_textures_settled` requires expected generation,
  `Ready`/complete, geometry residency, no pending detail request, settled
  pixels and quiet texture counters, and raises on a terminal error. New
  `wait_complete_hold` watches for a late error after the first visible frame.
  A later successful completion after the initial handoff is a no-op; a later
  failure is still surfaced.

## Gotchas

- Building `tests/import-isolation/Tests.ImportIsolation.vcxproj` directly
  loses `$(SolutionDir)`, so the test asset/worker paths bake the project
  directory. Pass `/p:SolutionDir=<repo>\\` (the wrapper does this).
- The detail service must stay available long enough for the first visible
  request (the render thread needs to upload and frame the coarse proxy). A
  short grace from time zero ends the replay too early and leaves
  `requestedDetails = 1` forever. The initial grace is therefore 60 s and only
  the post-request idle grace is short.
- Do not run two `Preview3D.exe` instances; single-instance activation steals
  the window.

  regions that only become visible much later. Today those regions use the
  already-resident coarse proxy until the model is reopened.
- T34/T35: run the T23 hold on a low-GPU-budget/UMA device; a smaller detail
  target may shed texture detail (bounded degradation), which must still not be
  reported as a terminal ResourceLimit.
