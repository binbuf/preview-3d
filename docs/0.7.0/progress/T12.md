# T12 — TGA/DDS textures and ORM ambient occlusion

## Reusable facts

- **Decoders (product-owned, no new third-party code).**
  - `import-worker/src/TgaImageDecode.{h,cpp}` — type 2/10 true-color,
    24/32-bit, no palette/interleave, zero canvas origin. Honors TGA origin
    bits; decodes RLE packets against exactly `width*height` texels; converts
    BGR(A)→RGBA8.
  - `import-worker/src/DdsImageDecode.{h,cpp}` — validates `DDS ` magic,
    `dwSize==124`, `ddspf.dwSize==32`, resource shape, DX10 header, and the
    payload extent. Legacy `DXT1`/`DXT5`/`ATI2`/`BC5U`; DX10 BC1/BC3/BC5/BC7
    UNORM + `_SRGB`; uncompressed legacy 24/32-bit RGB(A) and DXGI
    `R8G8B8A8`/`B8G8R8A8` UNORM/SRGB.
  - `import-worker/src/RasterRgbaSupport.h` — shared `FinalizeRgba8`: bounded
    maxDimension area downscale in linear light + color-aware
    `GenerateRasterMips`.
  - `ImageFormatSniff` gained `Dds` (magic) and `Tga` (strict 18-byte header
    candidate because TGA has no magic); `HasDecodableImageExtension` accepts
    `.tga`/`.dds`.
- **Budget behavior.** Both decoders use `TextureDecodeOptions` and
  `options.Cancelled()`. TGA has no codec-native scaler, so its decoded source
  must fit `maxDecodedBytes`/`maxPixels`; smaller `maxDimension` triggers the
  shared area downscale. DDS BC drops oversized authored mips until the base
  fits `maxDimension` (or rejects when even mip 0 is too large); uncompressed
  DDS decodes only level 0 and regenerates mips.
- **Dispatch sites updated:** `GltfAdapter`, `ObjAdapter`, `FbxAdapter`,
  `UsdAdapter`, `AssimpTextureDecode`, and `compatibility-host/src/OpenUsdHost`.
  Each uses a `Tga`/`Dds` case in the existing sniff switch; failures stay soft
  (`nullopt`) and become the adapter's bounded texture warning.
- **Sidecar allowlist.** `shared/import-broker/src/SidecarPathResolver.cpp`
  `IsImageExtension` now includes `.tga`/`.dds` for glTF/OBJ/FBX/Assimp/USD.
  `UsdAdapter::ImageExtensionMatches` and the host's equivalent also map those
  extensions. 3MF keeps its spec content-type PNG/JPEG policy.
- **ORM/AO.** `interactive-viewer/src/app/D3D12ViewerPath.cpp` samples
  `gMetallicRoughness`: `metallic*=mr.b`, `roughness*=mr.g`,
  `occlusion=saturate(mr.r)`. AO multiplies indirect diffuse, environment
  reflection and ambient terms only; `EvaluateLight` direct specular has no AO
  factor. The 72-byte `MaterialPayload` is unchanged, so AO is full-strength.
  `D3D12ViewerPath::TexturedPixelShaderSource()` exposes the exact shader text
  for the no-GPU unit contract.
- **Fixtures.** `tests/fixtures/textures/` is fully repository-owned and
  regenerated by `python tests/fixtures/textures/generate_textures.py`:
  TGA 24/32 uncompressed + RLE, DDS BC1/BC3/BC5/BC7, BC1 mip chain,
  RGBA8, truncated, an OBJ+MTL package (TGA base color + BC5 normal), a bad
  TGA/DDS package, and a glTF ORM package (R=32, G=200, B=20).
- **Tests.** `tests/import-isolation/TextureTgaDdsTests.cpp` tags
  `[texture-tga]`, `[texture-dds]`, `[texture-ao]`; shader AO contract in
  `tests/unit/PresentationTests.cpp` tag `[texture-ao]`.
- **Fuzz.** `tests/fuzz/GltfFuzz.cpp` domain 7 = TGA, 8 = DDS;
  `prepare_gltf_seeds.py` copies the TGA/DDS fixtures into the seed set.

## Gotchas

- DDS BC level offsets need an explicit zero for the first level; calling
  `ComputeImagePixelBytes(..., mipLevels=0)` returns `nullopt` by contract.
- `ComputeImagePixelBytes` caps mip levels at the full chain; clamp the DDS
  header count before calling it.
- TGA `map_Bump` in MTL may not produce a ufbx normal map; `norm` is the
  reliable OBJ fixture keyword.
- The TGA 8x8 alpha gradient gives 31 at x=0; the 4x4 fixture gives 63.
- Windows linker occasionally restarts as 64-bit on `usd_m.lib`; benign.

## Follow-ups

- `MSFT_texture_dds` alternate-image indexing remains unparsed; direct DDS
  sidecars work. A later glTF-extension task can wire it to this decoder.
- `occlusionStrength` is not represented by `MaterialPayload`; if a source
  authors it, the current renderer ignores it (full-strength AO). A future
  material-contract task can add a flag/value without changing byte size or an
  ADR-approved growth.
- 3MF texture2d content types remain PNG/JPEG only (lib3mf enum); TGA/DDS in a
  3MF package is still a typed content-type rejection.
