# T26 — bounded order-independent transparency

## Status: done

Weighted blended OIT (WBOIT) is the product transparency path. The full gate
passes at `TestResults/render-quality/T26` (72/72 focused checks, 11 captures,
external qualification available, review recorded). The sorted straight-alpha
path is retained only as a recorded fallback.

## Reusable facts

- **Algorithm**: two fixed `RGBA16F` targets — weighted accumulation
  (`rgb=color*coverage*weight`, `a=coverage*weight`) and revealage
  (`(coverage,0,0,coverage)`). Resolve: `scene*reveal + average*(1-reveal)` in
  linear HDR before tone mapping. No peel count, no per-pixel linked list.
- **Weight**: `gViewport.z` carries eye distance; clamp `[1e-2, 300]`.
- **Caps**: `D3D12ViewerPath::kOitSupportedLayerLimit == 8`; target bytes
  `OitTargetBytesForExtent(1280,900) == 18,219,008`; accounted in the DXGI
  budget. Beyond 8 layers the result is stable but a weighted average.
- **Fallback reasons** (field 244): 0 none, 1 allocation failure, 2 forced,
  3 unsupported extent, 4 device loss, 5 diagnostic-channel active. Effective
  algorithm in field 243: 0 sorted, 1 WBOIT.
- **Debug fields 243–258** (guard `PREVIEW3D_ENABLE_TEST_CONTROL` +
  `--app-smoke`, max 258): algorithm/reason/cap/draws/bytes, forced fallback
  (248), permutation (249), bytes high (250), last pick id (251), resolve used
  OIT (252), resolve diagnostic (253: 1 accum, 2 reveal, 3 scene, 4 accum alpha),
  pick completions (254), normalized pick (255), viewport left/top (256),
  viewport right/bottom (257), absolute physical pick (258).
- **Picking**: separate pass after colour, writes only the `R32_UINT` target and
  depth, reuses material discard. Id = `instanceId ? instanceId : chunkId`;
  the value observed by the test surface is the low 16 bits in the current
  snapshot namespace. Hidden/back layers are absent from a pick census.
- **Cutout fix**: the shader previously forced base-color texture alpha to 1
  for non-layer materials, so textured `MASK` cutouts never discarded. It now
  preserves sampled alpha for MASK/BLEND; opaque/masked display alpha is still
  1 after the cutoff.
- **Shader compile**: OIT variants are compiled with the `OIT_PASS` macro
  (`CompileShader(..., defines)`); the non-OIT `PixelOutput` still writes
  `SV_TARGET1` pick.
- **Resolve constants**: `gBackground.w` is the per-frame OIT flag;
  `gResolve.w` is 12 normally, or an OIT diagnostic mode 1–4.

## Tests / lanes

- `Tests.Unit.exe "[layered-transparency]"` — 5 cases / 1235 assertions:
  order invariance, revealage/coverage, weight bounds, target budget, shader
  source + OIT compile.
- `layered_transparency.py` serial lanes: unit, `[shared-section-validator]`,
  `[hostile-worker]`.
- Generated fixtures: `layered-glass.glb` and `layered-glass-permuted.glb`.
  Their world positions are identical; only primitive/index/node order changes.
- The fixture quads carry `TANGENT` + `COLOR_0` so the importer selects the
  complete-vertex textured pipeline (otherwise they use the compact legacy
  shader and no OIT/debug/cutout/emissive path).
- Pick verification uses `_pick_census`: scan field 258 over the physical
  viewport rect (fields 256/257) and compare exact ids. It avoids the
  capture/DPI click mapping.

## Gotchas

- The evidence window is 150% DPI: `PrintWindow` captures a logical-size crop
  while the swap chain/pick target and `ViewportRect` are physical (~1898×1273
  for a 1280×900 request). Clicking image coordinates directly, or normalizing
  by the image height, misses. Use the pick census with field 258, or scale
  relative to the physical viewport in a future harness fix.
- `GetClientRect`/capture width 1265 vs `ViewportRect` right 1898 is expected
  here; do not infer the pick target size from the PNG.
- The viewer persists ground-axis/native-orientation settings. Always reset
  ground axis to Automatic (`field 70=0`) and native orientation off
  (`field 30` when query 21 is set) before controlled captures, or the model
  dimensions/orientation change between runs.
- The sorted fallback permutation delta is small (~1e-4 to 1e-3 MAE depending
  on framing); the OIT delta is exactly 0. Use `>0.0001` for the fallback,
  not a large threshold.
- Kill stale `Preview3D` processes before the gate; the single-instance path can
  steal the window.
- The import worker pool itself is fine; an earlier failure was a shader compile
  error in the OIT PS, reported as a graphics startup failure (not an import
  failure).
- No accepted baseline promotion; external Car/Camera images stay local/ignored.
