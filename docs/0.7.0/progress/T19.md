# T19 - 0.7.0 compatibility qualification and docs

## Reusable facts

- **Evidence file:** `docs/0.7.0-QUALIFICATION.md`. Raw reports live in
  `TestResults/qualification/` (app smoke, visuals, unit/import logs) and
  `artifacts/compat/Release.json`.
- **Corpus gate:** `x64\Release\Tests.ImportIsolation.exe "[compat]"` — 312
  assertions / 2 cases, pass. Report: `[write-compat-report]`. The manifest is
  still T01 baseline only (glTF, STL, PLY, STEP); do not claim open rates for
  other families from it.
- **Suites:** `Tests.Unit.exe` 465 cases / 155,886 assertions pass;
  `Tests.ImportIsolation.exe` 506 cases (501 pass, 5 typed skips) / 303,956
  assertions pass.
- **App smoke requires Debug:** `--app-smoke` and the WM_APP+104 surface are
  compiled out of Release (ADR-0040). Reports are JSON; the visual lanes write
  per-machine goldens under `TestResults/qualification/`.
- **Rebuild Debug viewer *and* StepHost** before app smoke. `/t:Preview3D` does
  not build `Preview3DStepHost`; a stale Debug step host fails with code 26
  (`StepHostFailure`) at phase 6.
- **D3D12 root-signature budget:** 64 DWORDs total, including 2 per CBV and 1
  per descriptor table. The textured signature has one CBV + five tables + b1 +
  b2, so b1+b2 must be <= 57. T18's 33+36 broke `CreateRootSignature` and the
  viewer reported "The textured D3D12 root signature could not be created."
  Current layout: b1 = 25 (transposed 3x4 local in three float4 rows, 3x3
  normal in three float4 columns, pick id), b2 = 32 (five material float4s +
  three packed lobe float4s; emissive strength rides in `gEmissiveFactor.a`).
  Total exactly 64.
- **Root constants are not matrices in the shader anymore.** Use explicit
  `float4` rows and `dot` for the textured draw transform; `row_major float3x4`
  / `float3x3` layout ambiguity made `gPickId` read zero and broke GPU picking.
- **Picking:** `query 29` is the projected bounds-min for point clouds, not the
  center. Point-cloud pick can be sensitive to the fixture; `ground_axis.py`
  scans a small offset for points.
- **Installer/SBOM:** `Tests.Unit.exe "[format-installer]"`,
  `python tests/app-smoke/thumbnail_registration.py`,
  `powershell -File packaging\Test-ReleaseMetadata.ps1 -RepositoryRoot <repo>`.
  Assimp is `assimp 6.0.4#3`; tinyexr is vendored from TinyUSDZ and declared as a
  vendored component, not a vcpkg port.
- **Performance lane:** `python tests/performance/qualify.py <fixture>
  --configuration Release --output TestResults/qualification/perf-*.json
  --runs 1 --duration-ms 3000 --frames 600`. Report `summary` has
  `firstBackgroundMs`, `firstGeometryMs`, `frameP95Ms`, `inputToPresentMs`,
  `viewerPeakPrivateBytes`, `workerPeakPrivateBytes`. The 16 ms compatibility
  frame/input gates pass; the 150 ms performance-reference startup gate is not
  claimed on this workstation (first background ~0.84-0.95 s, includes first-use
  shader/PSO compile). Repeat on the reference system before any timing claim.
- **Dependency check:** `dumpbin /dependents` on `x64\Release\Preview3D.exe` —
  only system DLLs + shipped VC runtime; no OCCT/Assimp/fastgltf/lib3mf/OpenUSD.
  The worker and hosts are static; no `TK*.dll` in the Release tree.
- **Version:** the tree still reports release version `0.6.7`; 0.7.0 has not been
  cut. Do not "fix" the version in a qualification task.
