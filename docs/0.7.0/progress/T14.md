# T14 — Studio IBL and neutral tone map (first slice)

## Reusable facts

- **Environment source.** Product-owned procedural studio, no HDRI/user file.
  `interactive-viewer/src/render/StudioEnvironment.{h,cpp}` is CPU-only (no
  D3D12/DirectXMath), so Tests.Unit exercises the shipped baker. Three
  rectangular softboxes (key/fill/rim), an overhead strip and a floor/ceiling
  gradient are evaluated in direction space.
- **Bake shape.** Defaults 128 texels/face, 6 specular mips, 48 GGX samples.
  `BakeOptions` clamps faceSize to 4..256 (power of two) and mips to the full
  chain. Texture is `R32G32B32A32_FLOAT` cube, ~2 MiB, uploaded once on the
  direct queue during `D3D12ViewerPath::Initialize`.
- **Face mapping / mip policy.** Direct3D cube order +X, -X, +Y, -Y, +Z, -Z;
  `CubemapDirection` is the single source of truth for both bake and tests.
  Roughness 0 -> mip 0, roughness 1 -> last mip; shader uses
  `roughness * gEnvironment.w` where `w = mipCount - 1`.
- **SH.** `ShCoefficients` stores irradiance/pi directly (band weights already
  applied), so the shader is `sum(basis_i * gSh[i].rgb)`. `ReferenceIrradianceDivPi`
  is the numeric convolution reference. SH9 is low-frequency; tests use a 35%
  tolerance against the reference because the key softbox is sharp.
- **Frame constants.** `kConstantBufferSlotBytes` is now 512. Textured pixel
  shader `FrameConstants` = viewProjection, eyeSelection, viewport, lighting,
  world-from-camera quaternion, environment (intensity, yaw, exposure, last
  mip), `gSh[9]`.
- **World-stable reflections.** Vertex shader still works in camera space;
  the pixel shader rotates normal/view back with `RotateWorldFromCamera`. The
  key/fill `EvaluateLight` remains camera-relative.
- **Descriptor gotcha.** D3D12 allows only one shader-visible CBV/SRV/UAV heap
  at a time. The cube SRV is appended to each model material heap at
  `ModelResources::environmentDescriptorIndex`; `WriteEnvironmentSrv` rewrites
  it after `RebuildMaterialDescriptors`. Do not give the environment its own
  heap and bind both.
- **Tone curve.** Khronos PBR Neutral (`startCompression = 0.76`,
  `desaturation = 0.15`) times exposure, then sRGB. CPU copy in
  `NeutralToneMapLinear`/`NeutralToneMap`; HLSL copy in `kTexturedPixelShaderSource`.
  `DisplayMap`/`StudioEnvironment`/`EnvironmentIrradiance` are gone from the
  textured path.
- **Clay / Directional.** Clay keeps the grey material and roughness .82 but
  suppresses IBL specular to 25%. Directional keeps its hard key and adds
  0.25x irradiance + 0.35x specular ambient.
- **Legacy path.** The compact/position-only and point shaders still use the
  old analytic view-space studio light. That is the temporary developer
  fallback; the material-aware textured path is the one T14 replaced.
- **Screenshot lane.** `tests/app-smoke/studio.py` generates a six-sphere glTF
  (white/black/red dielectric, rough/polished metal, glass), opens it through
  `--app-smoke`, selects modes through WM_APP+104 fields 87/88, captures with
  `PrintWindow(PW_RENDERFULLCONTENT)`, orbits once, and compares a 64x64
  downsampled RGB MAE with `studio-golden.json` (threshold 0.06).

## Gotchas

- The first attempt bound two `CBV_SRV_UAV` heaps (model + environment) in one
  `SetDescriptorHeaps`. D3D12 debug message 554 fired and the render thread
  stopped presenting after the first model draw. One combined heap fixed it.
- The screenshot lane must rebuild Debug after renderer changes; `Tests.Unit`
  compiles `D3D12ViewerPath.cpp`, so the Release unit binary can be green while
  `x64\Debug\Preview3D.exe` is stale.
- `PrintWindow` reflects the last *presented* frame. If a debug-layer error
  stops the render thread, the capture stays on the loading card even when the
  smoke query reports Ready. Check `debugErrors_` / stderr before assuming the
  fixture failed.
- Full `Tests.Unit.exe` has two pre-existing failures unrelated to T14:
  `FormatRegistrationTests` still expects `dae` to be rejected, and
  `ActiveInstanceTests` still expects `model.iges` to be rejected. Both formats
  shipped in T08/T10. The task verify filter is green.
