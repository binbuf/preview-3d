# T25 — texture-driven clearcoat, specular, sheen and transmission

## Status: done

Protocol v14's thirteen fixed material slots, glTF import of the eight
extension maps, the bounded D3D12 layout and the GPU map-variation lane all
landed. The front-matter gate passes at `TestResults/render-quality/T25` with
140/140 checks and a recorded image review.

## Reusable facts

- **Wire version is 14** (`model_core::kCurrentProtocolVersion == 14`).
  `MaterialPayload` 440 bytes; `ChunkDescriptor` 208 bytes with
  `kMaxDependencyIds == 16`; `DetailRequest` 216 bytes.
- **Material slots** (`MaterialPayload.h`):
  `{0 baseColor, 1 metallicRoughness, 2 normal, 3 emissive, 4 occlusion,
  5 clearcoat, 6 clearcoatRoughness, 7 clearcoatNormal, 8 specular,
  9 specularColor, 10 sheenColor, 11 sheenRoughness, 12 transmission}`.
  Slots 13–15 must be zero.
- **Payload offsets**: `clearcoatNormalScale` 128, `slotFlags[13]` 132,
  `slotUvOffset[12][2]` 184, `slotUvScale[12][2]` 280,
  `slotUvRotation[12]` 376, `reserved[4]` 424.
- **Channels/color spaces**: clearcoat R, clearcoat roughness G, clearcoat
  normal RGB (Normal), specular factor A (Linear), specular color RGB (sRGB),
  sheen color RGB (sRGB), sheen roughness A (Linear), transmission R (Linear).
  Factor × map is applied per texel.
- **Renderer layout**: 15 single-descriptor SRV tables + 25-DWORD b1 draw block
  + b0/b2 CBVs = 44/64 root DWORDs. Material CBV stride 1024 bytes; record
  560 bytes. Neutral descriptors: 13 (one per material slot) then cubemap
  (`t4`, root 5) and BRDF LUT (`t6`, root 9).
- **Root parameter map**: slots 0–3 → 1–4, slot 4 → 6, slots 5–12 → 10–17.
  Shader registers: t0,t1,t2,t3,t5,t7..t14.
- **Debug surface**: channels 24–30 are effective clearcoat/roughness,
  specular factor, IOR-tinted F0, sheen color, transmission, coat normal and
  sheen roughness. Field 233 selects extension slot 0–7; 234–242 read its
  flags/offset/scale/rotation/packed binding/chunk id; 242 is
  `clearcoatNormalScale`. The app guard is `wParam <= 242`.
- **Import**: `GltfAdapter.cpp` resolves the eight maps through the shared
  `resolveSlot` path (own sampler/UV set/transform/color space). UV1 stays
  unbound with `kTextureFeatureUnsupportedUvSet` (4000). No drop-warning is
  emitted for the now-supported maps.
- **Bridge**: `ImportedMaterial` has eight named extension image ids plus
  `ImageChunkId(slot)`; `RenderThread` and `D3D12ViewerPath` bind all 13 slots.

## Gotchas

- `common.encoded_png`/`studio.png` writes **RGB** (3 bytes/pixel), not RGBA.
  Use `fixtures._rgba_png_data_uri` for maps whose authored channel is alpha
  (specular factor, sheen roughness).
- The viewer presents glTF Y-up. A quad in the model XY plane at constant Z
  faces the front camera; the earlier XZ-plane version lay flat on the ground
  and disappeared in the front view. Double-sided avoids winding surprises.
- Channel 24 packs `(clearcoat, clearcoatRoughness, 0)`, so roughness variation
  is component 1. Channel 26 is IOR-tinted F0; its authored red gradient is
  small (0.04 scale), so the T25 delta threshold for it is 0.004.
- `material_records` now queries fields 233–242; a stale viewer binary will
  report empty extension slot metadata.
- Do not run two `Preview3D.exe` instances. Kill stale viewers before the gate.
- Device removal recovery reimports from retained source; poll material records
  for up to 90 s rather than assuming the next frame is ready.

## Follow-ups

- T26/T27: keep the map-driven transmission factor, then replace the
  alpha-carried interface Fresnel with transmitted-scene sampling, tint and
  rough refraction. Preserve the T24 clearcoat energy layering.
- T33: add mip/anisotropic filtering; the T25 maps use nearest/clamp and
  wrap/linear samplers as authored, not a new global filtering policy.
- Future UV1 support: adding a second TEXCOORD set is a vertex-layout + wire
  change; do not alias UV1 maps to UV0 in the meantime.
- Optional: an image-capable reviewer should re-confirm the final T25 capture
  set before any reference promotion; T25 promotes none.
