# T11 — USD primitives, points and crease tolerance

## Reusable facts

- **Fast-path classification.** `import-worker/src/UsdAdapter.cpp` adds
  `StagePolicy::needsCompatibilityHost`. Visible `GeomSphere`, `GeomCube`,
  `GeomCone`, `GeomCylinder`, `GeomCapsule`, `GeomPoints`, authored creases, and
  an **authored** non-`none` subdivision scheme set it. `ImportUsd` maps it to
  `ImportErrorCode::UnsupportedComposition` before the render-scene converter or
  `BoundedChunkWriter` exists. No new error code: the already-tested atomic
  fallback path and hostile protocol cases are reused unchanged.
- **Preserve fast path.** TinyUSDZ reports an unauthored `subdivisionScheme` as
  its default (`catmullClark`), so classification must check
  `mesh->subdivisionScheme.authored()`. Checking only `get_value() != none`
  silently pushed ordinary meshes (for example `materials.usda`) to the host and
  broke fast-path tests.
- **Host geometry.** `compatibility-host/src/OpenUsdHost.cpp` now recognizes
  `UsdGeomMesh`, the five procedural Gprims and `UsdGeomPoints` via
  `IsHostGeometryPrim`. `NormalizeProduction` emits one geometry record set per
  prim path and creates `MeshInstance` records for all of them; material
  binding for non-meshes uses `BoundMaterial`, while mesh subsets still use
  `GroupMaterial`.
- **Tessellation parameters (fixed, deterministic).**
  - sphere: 24 longitude x 16 latitude bands = 720 triangles;
  - cube: 12 triangles (6 quads, face normals);
  - cylinder: 24 radial segments, capped = 96 triangles;
  - cone: 24 radial segments, capped base = 48 triangles;
  - capsule: 24 radial x 8 latitude bands per hemisphere + spine = 768 triangles;
  - `radius`/`height`/`size` are honored; capsule `height` is the cylinder
    spine length, so total axis extent is `height + 2*radius`;
  - `axis` supports X/Y/Z (default Z) by proper rotations, preserving winding;
  - `extent` is ignored as geometry and bounds are recomputed from vertices.
- **Points.** `UsdGeomPoints` emits `ChunkTopology::PointList` chunks with
  `PositionNormalUv0TangentColor_F32`, `indexCount == 0`, displayColor and
  displayOpacity, per-chunk origin/bounds, and `kGeometryHasColors` when either
  primvar is authored. Chunks are capped by `import_worker::kChunkPoints` and
  the section byte capacity. Authored `widths` are ignored with one optional
  warning; the viewer's existing point-splat size policy owns screen size.
- **Control cage.** The host no longer fails on creases. An authored non-`none`
  subdivision scheme increments `optionalWarnings` (Degraded) and triangulates
  the authored cage. Holes are still skipped by the existing cage loop. No
  OpenSubdiv and no subdivision-level option.
- **Budgets.** Gprims reuse `kTierBTriangleLimit`, `kTierBVertexLimit`,
  `kTierAObjectLimit`, the section capacity and the 30 s host deadline. Points
  consume the vertex budget and the object/instance caps. No new numeric limit.
- **Fixtures.** Original repository-owned files in `tests/fixtures/usd-spike/`:
  `primitives.usda` (axes Y/X/Z authored), `primitivesZ.usda` (default Z),
  `usd_points_rgb.usda`, `subdiv_cube_cc.usda`, and
  `mixed_mesh_primitives.usda`. No third-party fixture/license was imported.
  Hashes and byte counts are in `tests/fixtures/usd/manifest.json` and the
  fixture README; `python tests/fixtures/usd/verify.py` verifies them.
- **Tests.** `tests/import-isolation/UsdProtocolTests.cpp`, tag
  `[usd-primitives]`, covers all five primitives and axes, exact counts/bounds,
  colored/opacity points, the creased control cage warning, mixed geometry,
  fast-path preservation, malformed-terminal behavior, and the before/after
  batch fallback protocol cases.
- **Docs.** `docs/FORMAT-SUPPORT.md`,
  `docs/design/03-file-formats-and-ingestion.md`, and
  `docs/design/adr/0067-usd-gprim-points-control-cage.md`.

## Gotchas

- `UsdGeomCapsule.height` is the spine length excluding the hemisphere caps;
  radius default is 0.5 and height default is 1.
- The host's schema `GetXAttr()` returns the fallback for unauthored attributes,
  so use `HasAuthoredValue()` when "unauthored" must mean "no warning/no host".
- Generated cap/cone vertices need their own normals; reusing radial side
  vertices for a flat cap produces a plausible but wrong normal field.
- `PointList` validation requires `indexCount == 0`; do not attach the synthetic
  deindexed identity buffer that `TriangleList` uses.
- The Windows linker occasionally relaunches as a 64-bit linker on
  `usd_m.lib`; this is benign.

## Follow-ups

- USD curves/NURBS remain `UnsupportedRequiredFeature`; T17 adds line topology,
  after which a follow-up can emit polylines or tube approximations.
- Point primvar `widths`, `normals`, and `ids` are ignored; only displayColor and
  displayOpacity are consumed. A later renderer/point task can add per-point
  size if the wire format grows a field for it.
- Point-instancer prototypes that are procedural Gprims are now expanded by the
  host, but no dedicated fixture covers that combination yet.
- Hole indices on a subdivided mesh are silently skipped as part of the cage;
  decide later whether they deserve an explicit warning.
- Full Catmull-Clark/Loop evaluation and a bounded subdivision-level option
  remain out of scope; the control cage is the accepted preview.
