# T01 — Compatibility corpus and baseline scoreboard

## Reusable facts

- Manifest: `tests/compat/manifest.json` (schema 1). Entry `path` is relative
  to the repository root, because the corpus spans
  `interactive-viewer/test-assets/` and `tests/fixtures/`.
- Harness: `tests/import-isolation/CompatCorpusTests.cpp`, tag `[compat]`.
  Hidden evidence case: `[write-compat-report]`.
- Report: `artifacts/compat/<Configuration>.json` (path-free: ids only).
- Build (from repo root):
  `msbuild Preview3D.slnx /t:Tests_ImportIsolation /p:Configuration=Debug /p:Platform=x64`
  (and `Release`). Building the `.vcxproj` directly puts the exe under
  `tests/import-isolation/x64/<Config>/`; the accepted verify path is the
  solution build's `x64\<Config>\Tests.ImportIsolation.exe`.
- Checks:
  - `x64\Debug\Tests.ImportIsolation.exe "[compat]"` — 312 assertions pass.
  - `x64\Release\Tests.ImportIsolation.exe "[compat]"` — 312 assertions pass.
  - `x64\Release\Tests.ImportIsolation.exe "[write-compat-report]"` — writes
    `artifacts/compat/Release.json`.
- Outcome semantics: `opened` = ok + geometry + no warnings; `degraded` = ok +
  geometry + at least one warning; `failed` = `!ok`, exact `ImportErrorCode`.
- Warning ids today: `optional-feature` (`ImportStatusPayload`), and
  `texture-fallback` (`ImportStatusPayload::textureWarnings` or a
  `ChunkTextureWarning` chunk). T04/T05/T12/T13 should extend this mapping when
  they add categories.
- Host-required entries set `requiresHost` (compatibility host) or
  `requiresStepHost` (STEP host) and become a report-only `skipped` when the
  executable is absent. The `[compat]` case warns and continues, never fails.
- `ImportSessionRequest` runs with product section/chunk caps and both host
  paths supplied; Step entries therefore use the dedicated host even on a
  worker-only build.

- `basisu_corrupt_ktx2` is the baseline `degraded` row: geometry publishes and
  a `texture-fallback` warning is recorded.

## Gotchas

- The in-test JSON reader is deliberately narrow (no comments, no trailing
  commas). Keep the manifest plain JSON.
- `expectedWarnings`, when present, is an exact ordered comparison (the
  collector sorts). Omit it when only "any warning" is intended.
- `Draw-heavy` failing is not a T01 defect; do not "fix" it here.
- `tests/fixtures/{fbx,usd,3mf}-spike` store `.base64` files, so they are not
  directly importable by this corpus yet. The breadth tasks should either decode
  them to a committed fixture or add a directly readable equivalent.
