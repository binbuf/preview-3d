# T22 — authored material, UV, normal and AO semantics

## Status: partial slice landed (GPU shading application deferred)

The wire/import/validation/compatibility/cache half of T22 is implemented and
tested. The renderer-side shader/root-signature integration (per-material slot
CBV, normal-scale application, independent occlusion sampling) was reverted
after it produced a reproducible textured-draw hang on this workstation; see
Follow-ups. The tree builds and the serial unit/import/hostile/cache lanes are
green.

## Reusable facts

- **Wire version is 13** (`model_core::kCurrentProtocolVersion == 13`).
  `MaterialPayload` is 244 bytes; `ChunkDescriptor` is 176 bytes (eight
  dependency ids); `DetailRequest` is 184 bytes; `kMaxDependencyIds == 8`.
- **Material image slots** are `{baseColor, metallicRoughness, normal,
  emissive, occlusion}`; slots 5..7 must stay zero. Occlusion no longer shares
  the metallic-roughness red channel.
- **MaterialPayload v13 additions**: `normalScale`, `slotFlags[5]`
  (uv set 0-7 + per-slot U/V address + nearest), `slotUvOffset[4][2]`,
  `slotUvScale[4][2]`, `slotUvRotation[4]`. Slot 0 keeps the legacy
  `uvOffset/uvScale/uvRotation` fields.
- **Supported UV sets: 0 only.** A texture referencing a higher set is left
  unbound (never aliased to UV0) and produces
  `model_core::kTextureFeatureUnsupportedUvSet` (4000).
- **Intentional compatibility conversions are explicit**, not silent:
  `kGltfFeatureTransmissionNoInterfaceSuppressed` (9) for IOR<=1 transmission
  (Suit) and `kGltfFeatureDegenerateBlendRecovered` (10) for a BLEND material
  with no alpha source. Host text lives in
  `interactive-viewer/src/app/CompatibilityText.h`.
- **Alpha mode is preserved** verbatim; an authored OPAQUE transmission keeps
  `alphaMode == Opaque` and relies on `kMaterialFlagTransmissive` for the
  renderer bucket. Update RenderThread/PSO selection together if that changes.
- **sRGB/linear** remain per-image (`ColorSpaceId`), not per-slot; a shared
  image used by color and data semantics is decoded into distinct chunks.
- **Cache identity**: `shared/model-core/include/model_core/CacheIdentity.h`
  defines `kDerivedCacheParserIdentity` (protocol/importer/material/vertex
  layout). `CacheEntryKey::parserVersion` defaults to it; schema is 4. A
  different parserVersion misses even with the same file identity.
- **Tests**: `Tests.Unit.exe "[material-lobes],[cache]"`,
  `Tests.ImportIsolation.exe "[material-semantics]"`,
  `"[shared-section-validator]"`, `"[hostile-worker]"`. T22 lanes are serial.
- **Generated fixture**: `tests/render-quality/fixtures.py::material_semantics`
  (10 probe spheres + mirrored normal-mapped sphere; normal scale 0/0.45/1,
  MR-red vs independent AO, UV1, per-slot transforms/samplers, MASK cutout,
  IOR 1 vs 1.5).
- **Verification wrapper**: `python tests/render-quality/verify.py --task T22
  --configuration Debug --output TestResults/render-quality/T22`. It runs the
  serial lanes, captures the profile, and records channel images/external
  survey. `tests/render-quality/review/T22-review.json` records the review.

## Verified behaviour

- Wire/validator: v13 descriptor and material validation, normal scale bounds,
  slot-flag/uv-set/transform bounds, five-slot sparse material dependencies,
  slots 5..7 rejection.
- glTF import: normal scale 0/0.45/1, per-slot `texCoord`/sampler/transform,
  independent occlusion image in slot 4, UV1 unsupported record + unbound
  slot, MASK cutoff, IOR=1 suppression record, authored alpha mode preserved.
- Fbx/Usd/3MF/OBJ/Assimp/STEP producers still compile against the widened
  record because the legacy fields are unchanged; their slot metadata defaults
  to identity.
- Cache: schema 4 and real parser identity; a changed identity misses.

## Flakes / gotchas

- Do not run two `Preview3D.exe` instances; a stale process steals single
  instance activation and the harness reports `WinError 1400`.
- The T22 capture lane waits for visible pixels; the microscope may still hit
  its T23 ResourceLimit (known defect).
- `material_semantics.py` currently asserts normalized wire records and image
  capture, not normal-scale/AO pixel values, because the shader application is
  reverted.
