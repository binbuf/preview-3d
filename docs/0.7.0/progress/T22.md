# T22 — authored material, UV, normal and AO semantics

## Status: done

The wire/import/validation/cache contract and the renderer-side shader
application are both landed and verified. The full T22 verification command
passes, including generated GPU numeric readback and the external
Car/Camera/Suit/microscope survey.

## Reusable facts

- **Wire version is 13** (`model_core::kCurrentProtocolVersion == 13`).
  `MaterialPayload` is 244 bytes; `ChunkDescriptor` is 176 bytes (eight
  dependency ids); `DetailRequest` is 184 bytes; `kMaxDependencyIds == 8`.
- **Material image slots** are `{baseColor, metallicRoughness, normal,
  emissive, occlusion}`; slots 5..7 must stay zero.
- **MaterialPayload v13 additions**: `normalScale`, `slotFlags[5]`
  (uv set 0-7 + per-slot U/V address + nearest), `slotUvOffset[4][2]`,
  `slotUvScale[4][2]`, `slotUvRotation[4]`. Slot 0 keeps the legacy
  `uvOffset/uvScale/uvRotation` fields.
- **Supported UV sets: 0 only.** A higher set leaves its slot unbound (never
  aliased to UV0) and produces
  `model_core::kTextureFeatureUnsupportedUvSet` (4000).
- **Intentional compatibility conversions** are explicit, not silent:
  `kGltfFeatureTransmissionNoInterfaceSuppressed` (9) for IOR<=1 transmission
  (Suit) and `kGltfFeatureDegenerateBlendRecovered` (10) for a BLEND material
  with no alpha source. Host text lives in
  `interactive-viewer/src/app/CompatibilityText.h`.
- **Alpha mode is preserved** verbatim; an authored OPAQUE transmission keeps
  `alphaMode == Opaque` and relies on `kMaterialFlagTransmissive` for the
  renderer bucket. Update RenderThread/PSO selection together if that changes.
- **sRGB/linear** are per image (`ColorSpaceId`), not per slot; a shared image
  used by color and data semantics is decoded into distinct chunks.
- **Cache identity**: `shared/model-core/include/model_core/CacheIdentity.h`
  defines `kDerivedCacheParserIdentity` (protocol/importer/material/vertex
  layout). `CacheEntryKey::parserVersion` defaults to it; schema is 4.

## Renderer binding (ADR-0080)

- Root signature: `b0` CBV (2) + six single-descriptor SRV tables (6) + `b1`
  draw constants (25) + `b2` material CBV (2) = 35 of 64 DWORDs.
- Texture registers: `t0` base, `t1` MR, `t2` normal, `t3` emissive, `t4`
  studio cubemap, `t5` occlusion. Root parameters 1-6 are those tables; `b1`
  is 7 and the material CBV is 8.
- `MaterialConstantData` is 304 bytes, stride 512 (`kMaterialConstantStride`).
  One buffer per `(material chunk, mirrored sign)`, `kFrameCount` regions;
  `RenderFrame` writes the current frame's region before binding. Buffers are
  UPLOAD heap, persistently mapped, included in accounting and upload estimate.
- Per-slot packed word: `addressU | addressV<<2 | nearest<<4 | uvSet<<5`, bit 9
  marks an unsupported set (the shader then skips the slot).
- A slot with `slotFlags == 0` inherits the legacy material-wide address/nearest
  bits, so pre-v13 producers keep their behavior.
- Buffers are shared only by draws with the same **material chunk and mirrored
  sign** (`MaterialConstantBuffer::materialChunkId/mirrored`). Instances cloned
  from shared geometry in `RenderThread` call
  `D3D12ViewerPath::EnsureMaterialConstants` when their effective material or
  handedness differs; without that call two draws overwrite one per-frame
  region and the last material wins.

## Shader semantics

- Slot 0 uses `uvOffset/uvScale/uvRotation`; slots 1-4 use the v13 arrays.
- `normalTexture.scale` multiplies sampled tangent-space XY before
  renormalization.
- AO comes only from `gOcclusion` (`t5`); MR red is never AO.
- Double-sided back faces reverse the geometric normal *before* the TBN.
- Mirrored instances multiply tangent `w` by the instance determinant sign
  (`gMaterialExtras.y`).
- Zero tangent falls back to `ddx/ddy` of the transformed normal-map UV and
  camera-space position.
- Every slot applies its own address mode and nearest/linear sampler; `None`
  outside `[0,1]` invalidates the slot instead of clamping into UV0.

## Flakes / gotchas

- Do not run two `Preview3D.exe` instances; a stale process steals single
  instance activation and the harness reports `WinError 1400`.
- The T22 capture lane waits for visible pixels; the microscope may still hit
  its T23 ResourceLimit (known defect).
- The old per-material CBV attempt hung because the sixth SRV table was added
  while the 32-DWORD inline material block still occupied the root budget.
  Free the inline block first (as ADR-0080 does).
- The debug material message range is 136-230; IDs 195-199 remain the ground
  highlight/background fields. `Preview3D.cpp` guards `wParam <= 240`.
