## The Release-probe defect (important)

T34's first acceptance run failed with:

```
Release viewer probe failed: viewer exited 2
```

Cause: `_release_probe` used `viewer.Viewer('Release', ...)`, and `Viewer`
always launches with `--app-smoke`. A Release binary correctly rejects that
Debug-only flag with the unknown-option usage exit (2). Fix: run
`Release/Preview3D.exe --app-smoke` and require exit != 0, then launch Release
normally and require `WM_APP+104` fields 0/105/107/300 to return 0.

First-failure evidence retained:
`TestResults/render-quality/T34-gate-first-failure.log` and
`TestResults/render-quality/T34-first-failure-report.json`.
